# SkillBridge

> SkillBridge bridges the gap between university computer science education and production software engineering. It provides structured, production-grade Backend Engineering and SQL Mastery tracks where students build real-world microservices, undergo senior staff engineer code reviews, and claim direct cash payouts via Stripe Connect Express. Founded to eliminate superficial tutorial hell and empower student developers with verifiable industry experience.

## What SkillBridge does

SkillBridge provides paid learning tracks and production code validation for aspiring software engineers. Students complete hands-on engineering modules, submit open-source GitHub repositories and live deployments, and receive rigorous line-by-line code reviews on error handling, database indexing, authentication security, and API idempotency. Upon approval by senior reviewers, students earn direct monetary rewards and verified certificates of completion.

- Production-grade Backend Engineering & SQL Mastery tracks
- Senior Staff Engineer code reviews with actionable feedback
- Direct cash payout rewards ($20 - $50 per module) via Stripe Connect Express
- Verified digital certificates for portfolio showcasing and resume building

## Tracks & Curriculum

- [Backend Engineering Track](https://skillbridge.dev/#curriculum): Master Node.js & Express architecture, stateless JWT & 2FA security, Stripe API integrations, and cloud deployment.
- [SQL Mastery Track](https://skillbridge.dev/#curriculum): Master relational schema normalization, B-Tree & Hash indexing, complex CTEs, window functions, and high-cardinality query performance.
- [Capstone Projects](https://skillbridge.dev/#curriculum): Full-stack production systems evaluated against enterprise security and performance standards.
- [Leaderboard & XP](https://skillbridge.dev/#reward-engine): Earn XP points, climb global rankings, and showcase top achievements to hiring partners.
